xstem API

Everything the panel does is available over JSON. Create a key under API keys, then call /api/... on your panel address. A key has the same rights as the user who made it. The interactive reference lives at /api/swagger.

Authentication

curl -k -H "Authorization: Bearer xs_YOURKEY" https://PANEL:8443/api/guests

The header X-API-Key: xs_YOURKEY works too. The panel ships with a self-signed certificate, so use -k or verify=False until you install your own in /etc/xstem/cert.pem and key.pem. Machines can be addressed by numeric id or by name. Errors return {"detail": "reason"} with a 4xx or 5xx status.

Endpoints

Access: user means any key, and users only see their own machines. admin means admin role or root@pam. root means root@pam only.

Examples

# list machines with live stats
curl -k -H "Authorization: Bearer $KEY" "https://PANEL:8443/api/guests?stats=1"

# create a VM (admin) - the response contains the generated root password
curl -k -X POST -H "Authorization: Bearer $KEY" -H "Content-Type: application/json" \
  -d '{"kind":"vm","name":"web-01","image":"debian-12","cores":2,"ram":2048,"disk":20}' \
  https://PANEL:8443/api/guests

# create a container
curl -k -X POST -H "Authorization: Bearer $KEY" -H "Content-Type: application/json" \
  -d '{"kind":"ct","name":"box-01","image":"ubuntu/noble","cores":1,"ram":512}' \
  https://PANEL:8443/api/guests

# reboot by name
curl -k -X POST -H "Authorization: Bearer $KEY" -H "Content-Type: application/json" \
  -d '{"action":"reboot"}' https://PANEL:8443/api/guests/web-01/power

# forward a public server port to port 80 inside the machine
curl -k -X POST -H "Authorization: Bearer $KEY" -H "Content-Type: application/json" \
  -d '{"guest_port":80}' https://PANEL:8443/api/guests/web-01/forwards

Discord bot

Needs pip install discord.py requests. The key owner decides what the bot may touch, so give it a panel user that owns only the machines you want it to control.

import asyncio, discord, requests
from discord import app_commands

PANEL = "https://PANEL:8443"
KEY = "xs_YOURKEY"
HEAD = {"Authorization": f"Bearer {KEY}"}

def call(method, path, **kw):
    r = requests.request(method, f"{PANEL}/api{path}", headers=HEAD, verify=False, timeout=20, **kw)
    if not r.ok:
        raise RuntimeError(r.json().get("detail", r.text))
    return r.json()

async def acall(*a, **kw):
    return await asyncio.to_thread(call, *a, **kw)

client = discord.Client(intents=discord.Intents.default())
tree = app_commands.CommandTree(client)

@tree.command(name="vps", description="List your machines")
async def vps(i: discord.Interaction):
    await i.response.defer()
    rows = await acall("GET", "/guests?stats=1")
    text = "\n".join(f"**{g['name']}** {g['status']} cpu {g['stats']['cpu']}% {g['ip']}" for g in rows) or "No machines."
    await i.followup.send(text)

@tree.command(name="power", description="start, shutdown, reboot or stop a machine")
@app_commands.choices(action=[app_commands.Choice(name=a, value=a) for a in ("start", "shutdown", "reboot", "stop")])
async def power(i: discord.Interaction, name: str, action: app_commands.Choice[str]):
    await i.response.defer()
    try:
        await acall("POST", f"/guests/{name}/power", json={"action": action.value})
        await i.followup.send(f"{action.value} sent to {name}")
    except Exception as e:
        await i.followup.send(f"Failed: {e}")

@client.event
async def on_ready():
    await tree.sync()

client.run("DISCORD_BOT_TOKEN")

Console over WebSocket

Connect to wss://PANEL:8443/ws/console/ID?key=xs_YOURKEY. Send keystrokes as text frames, and send {"resize":[cols,rows]} to resize. Output arrives as binary frames.
